Get the Android app

For Android phones and tablets.
Download the app
About 4 MB. Updates to the pages arrive by themselves; you only download again if the office tells you to.

Install

  1. Tap Download the app, then open the downloaded file (or find it in My Files → Downloads).
  2. If asked, allow Install unknown apps for Chrome or My Files.
  3. Samsung: if it is blocked, turn off Auto Blocker in Settings → Security and privacy until it is installed.
  4. If Play Protect warns, tap More details → Install anyway.
  5. Open the app. Allow notifications and location (choose "Allow all the time" if offered).
  6. Settings → Apps → this app → Battery → Unrestricted, so GPS keeps working during shifts.

Then connect

Office and owners: enter the company link and company password on the first screen.
Drivers: open Drivers, paste the company link, then log in with your name and passcode.
iPhone: open this site in Safari → Share → Add to Home Screen.
